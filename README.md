# ml-journey

Мой путь от бизнес-аналитика до ML-инженера.

## О себе
Бизнес-аналитик, работаю с данными каждый день: пишу SQL-запросы, готовлю выгрузки,
занимаюсь конвертацией данных между системами (маппинг полей, проверка качества).
Делал Telegram-ботов и голосовых роботов на no-code платформах для автоматизации
рутины в бизнесе.

Сейчас системно перехожу в ML-инженерию: классический ML на табличных данных,
прикладные LLM (RAG, агенты) и MLOps. В этом репозитории — решения задач
и проекты по ходу обучения: от анализа данных до модели в продакшн-обёртке.


## Стек
Python 3.12 · uv · Jupyter · NumPy · pandas · scikit-learn · CatBoost · LightGBM

## Структура
Репозиторий наполняется по мере обучения:
- `stage-1-python/` — Python, NumPy, pandas, EDA
- `stage-2-math/` — линейная алгебра, вероятности, статистика, A/B-тесты
- `stage-3-ml/` — классический ML, проекты: отток клиентов, прогноз продаж
- `stage-4…6/` — deep learning, LLM (RAG-бот в Telegram), MLOps
